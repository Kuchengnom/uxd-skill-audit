# Design Context

- **Target audience**: Developers and UX/design practitioners evaluating AI/design skills.
- **Use cases**: Reading structured, scored reviews of GitHub skills; comparing skills across a 4-dimension framework (Methodik, Transparenz, Validierbarkeit, Wartbarkeit).
- **Brand personality/tone**: Editorial / refined — calm, typography-led, restrained. Warm off-white palette with muted sage/earth accents, Georgia serif body. No AI-slop aesthetics (no gradients, glassmorphism, neon).
- **Tech**: Static Jekyll site, no JS, no web fonts, single stylesheet, CSS custom-property token system, WCAG AA target. Light + dark mode via `prefers-color-scheme`.
